# AlparLabs Print Agent - releases

Ejecutables publicados del **agente de impresión AlparLabs** para el Punto de Venta de Odoo
(impresión en comanderas ESC/POS sin IoT Box).

Este repositorio solo contiene versiones compiladas (`AlparPrintAgent.exe`) y su huella
SHA-256 (`AlparPrintAgent.exe.sha256`). Los agentes instalados descargan de acá las versiones
nuevas, verifican la huella y se actualizan solos en su ventana de mantenimiento.

No contiene código fuente, configuraciones ni datos de clientes. Las versiones se publican
automáticamente desde el repositorio privado del proyecto.
